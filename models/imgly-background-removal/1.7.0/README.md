# IMG.LY Background Removal Assets 1.7.0

Download the matching asset package:

https://staticimgly.com/@imgly/background-removal-data/1.7.0/package.tgz

Extract the archive, then copy all files and directories inside `package/dist`
into this directory. The runtime assets such as ONNX models and WASM files
should be direct descendants of this directory, not nested under another
`dist` directory.
